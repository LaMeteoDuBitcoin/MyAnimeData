# Projet Fun : MyAnimeData

## Contexte

J'ai envie de faire une application qui permet de visualiser les données de son anime liste de MyAnimeList d'une manière amusante avec des jeux et des graphiques.

## Conception

Un groupe de pages pour les visuels et un autre pour des mini jeux.
Tout les graphiques et mini jeux seront basé sur les données de l'anime list de l'utilisateur via l'API.

Une page du profile de l'utilisateur.
